# kpi_focus_layout / 中心核心指标型

适合经营分析、销售业绩、产值、订单总览、目标完成率等以一个核心数字或核心目标为中心的看板。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，主指标进中心或视觉重心，其他指标按优先级向左右、底部、页签或下钻分布。
- `PrimarySlot` 是核心 KPI 或目标进度。
- 周边数据负责解释核心数字来源、趋势、排行和异常。
- 不需要地图或 3D 时不要硬加主视觉素材。

## Shell 规则

核心 KPI 和周边业务模块默认 `CardShell`。只有无标题大底板或组合背景才使用 `PanelShell`。
