# ultra_wide_command_layout / 超宽综合指挥型

适合 3840x1080、32:9、大屏墙、综合指挥中心、交通/应急/能源调度等多系统多主题场景。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，中心主态势或主指标进视觉重心，其他指标按业务域和优先级横向分布。
- 横向扩展，不把普通 16:9 布局直接拉宽。
- `PrimarySlot` 是中心综合态势对象。
- 左右多列按业务域组织信息。
- 底部可放横向事件流、视频流、趋势对比。

## Shell 规则

中心态势优先 `PanelShell`。左右业务域模块和底部列表趋势默认 `CardShell`。
