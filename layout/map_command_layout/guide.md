# map_command_layout / 地图态势分布型

适合智慧城市、区域经济、交通、应急、水务、能源、网络安全等带地图、区域、点位、热力、轨迹的场景。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，地图或区域主态势进中心，其他指标按优先级向左右、底部、页签或下钻分布。
- `PrimarySlot` 是地图或区域态势。
- `OverlaySlot` 是地图点位、弹窗、区域标签和轨迹。
- 左右或上下的业务卡片必须解释地图数据，不要脱离区域语义。
- 点位密集时优先聚合、热力、筛选，不展开所有文字。

## Shell 规则

地图主容器优先 `PanelShell`。统计、排行、告警、趋势等模块默认 `CardShell`。
