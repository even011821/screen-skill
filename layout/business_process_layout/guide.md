# business_process_layout / 业务流程管理型

适合订单、工单、审批、项目、生产计划、MES、ERP、WMS 等业务流转类大屏。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，主业务对象或主流程进中心，其他指标按优先级向左右、底部、页签或下钻分布。
- `PrimarySlot` 是流程、表格或状态流转。
- `DetailSlot` 通常用于阶段进度、流程节点或明细补充。
- 统计卡只解释流程状态，不抢流程主体。

## Shell 规则

流程、表格、图表、列表都默认 `CardShell`。除非作为无标题大背景底板，否则不使用 `PanelShell`。
