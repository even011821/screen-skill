# equipment_monitor_layout / 设备运行监控型

适合电厂、能源、船舶、港口、机房、矿山、化工、产线和设备运维场景。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，设备主对象或主运行指标进中心，其他指标按优先级向左右、底部、页签或下钻分布。
- `PrimarySlot` 是设备、产线、厂站或系统主对象。
- `StatusSlot` 通常必须存在，用于告警、故障、维护、健康状态。
- 实时状态优先于历史分析。

## Shell 规则

设备主画面优先 `PanelShell`。参数、告警、趋势、维护记录默认 `CardShell`。
