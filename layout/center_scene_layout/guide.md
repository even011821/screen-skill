# center_scene_layout / 单主视觉环绕型

适合园区、工厂、楼宇、建筑、设备场景、3D、数字孪生等需求。核心是一个明确的主视觉，其他指标围绕主视觉解释状态、趋势和风险。

## 结构原则

- 槽位只限制大致位置和优先级，不固定放什么内容。先分析指标，主指标或主视觉进中心，其他指标按优先级向左右、底部、页签或下钻分布。
- `PrimarySlot` 是第一视觉焦点，占内容区主要面积。
- `ContextSlot` 放趋势、分类、构成、排行等解释性数据。
- `StatusSlot` 放告警、任务、设备状态、异常等当前状态。
- `DetailSlot` 只在数据较多时启用，可放底部趋势、明细或事件流。
- `OverlaySlot` 只附着在主视觉上，例如设备标签、场景弹窗。

## Shell 规则

- `PrimarySlot` 优先 `PanelShell`，因为它是中心主视觉区域背景。
- 其他带标题、承载图表/列表/指标的模块默认 `CardShell`。
- 用户指定 Shell 样式时优先服从用户指定。

## 导航适配

先选 TopNav，再读取真实高度。内容区从 `nav.reservedHeight + nav.contentGap` 之后开始，不能写死 90/110。
