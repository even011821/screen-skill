# 行业场景推断规则

## 行业 → 模块推荐

| 行业 | 推荐模块 | 典型指标 |
|---|---|---|
| 集团经营 | KPI卡片+排名+趋势图+大字报+地图+占比+告警 | 营收、利润、现金流、ROE、各BU排名 |
| 医疗/健康 | 门诊量+床位+设备+药品+区域分布+趋势+告警 | 门诊人次、床位使用率、设备在线率、药品库存 |
| 交通/城市 | 路况+拥堵+事故+调度+停车+趋势 | 车流量、拥堵指数、事故数、响应时间 |
| 能源/电力 | 用能+负荷+设备+告警+碳排+区域 | 用电量、峰值负荷、设备在线率、碳排放 |
| 园区/IoT | 设备+在线率+告警+能耗+巡检+分布 | 设备总数、在线率、告警数、能耗 |
| 制造/MES | 生产+工单+稼动率+停机+产量+质量 | 完成率、OEE、停机时长、良品率 |
| 物流/供应链 | 吞吐量+车辆+准点率+路线+异常 | 吞吐量、在途数、准点率、异常订单 |
| 金融/销售 | 交易+GMV+毛利率+排名+客户+风险 | GMV、毛利率、客单价、风险敞口 |
| 文旅/展陈/品牌 | 客流+会员+消费+活动+区域+热力 | 客流量、转化率、会员活跃、消费额 |
| 政务/党建/应急 | 组织+事务+请求+任务+活动+风险 | 组织覆盖、办结率、满意度、参与数 |
| 农业/环保/双碳 | 生态指标+水质+碳排+能耗+区域+趋势 | 碳排放、能耗、水质、生态评分 |

## 行业使用边界

行业场景只用于 mock 数据、指标命名、业务分组和文案生成，不参与 TopNav、Shell、widget、background 等 kit 组件选择。

主题选择以用户指定或 `themes/catalog.json` 的主题 id、别名和 CSS 文件为准；不要从行业反推 kit 组件，也不要把行业字段写入 kit 运行时 `meta.json`。
